# User Stories: KiteWin

## Story 1: Управление банком идей
- As a разработчик на Windows
- I want создавать, структурировать и просматривать архитектурные идеи
- So that все наработки сохраняются локально в SQLite с фильтрацией по статусу, платформе и избранному.
- Acceptance criteria:
  - Список отображается в левой колонке (300 epx) с бейджами статуса и платформы.
  - Детальная карточка позволяет редактировать заголовок, концепцию JTBD, целевой стиль и платформу.
  - Изменение полей сохраняется мгновенно без потери фокуса.
  - Иконки реализованы через Segoe Fluent Icons, без эмодзи.

## Story 2: Промпт-переводчик Antigravity
- As a prompt engineer / разработчик
- I want преобразовывать сырые тезисы в 3-частный промпт для Stitch или точечный эдит
- So that ИИ-агенты получают исчерпывающий контекст со строгими дизайн-токенами.
- Acceptance criteria:
  - Поддержка 5 режимов: План, Stitch, Точечный, Бриф, Действия.
  - 10 визуальных стилей с токенами: Claude Paper, Codex Minimal, Terracotta, Risograph, Linear Cockpit и др.
  - Индикатор плотности промпта (0-100%).
  - Копирование сгенерированного промпта в буфер одной кнопкой.

## Story 3: Двусторонняя P2P-синхронизация с Kite macOS
- As a пользователь Mac и Windows
- I want синхронизировать идеи между Mac и Windows по локальной сети
- So that изменения, сделанные на Mac, мгновенно попадают в Windows и наоборот.
- Acceptance criteria:
  - Клиент обращается к Kite macOS (`GET /api/ideas`, `POST /api/ideas`) на порт 24242.
  - Локальный HttpListener на Windows слушает порт 24243.
  - Дедупликация по UUID/названию с сохранением свежих данных.
  - Статистика синхронизации: получено с Mac, отправлено на Mac, общее число.

## Story 4: Каталог скиллов и плагинов Antigravity
- As a архитектор
- I want искать и просматривать каталог из 355 скиллов и 18 плагинов
- So that легко находить директивы (@design-md, @emil-design-eng) и вставлять их в спецификации.
- Acceptance criteria:
  - Быстрый поиск по имени, описанию и категории.
  - Переключение вкладок «Скиллы (355)» и «Плагины (18)».
  - Копирование идентификатора скилла.

## Story 5: Быстрый захват (Quick Capture)
- As a разработчик в потоке работы
- I want вызывать панель быстрого захвата по Ctrl+Shift+K
- So that за секунды зафиксировать мысль и вернуться к текущей задаче.
- Acceptance criteria:
  - Легкое всплывающее окно без рамки с фокусом на поле ввода.
  - Сохранение по Enter, закрытие по Esc.

## Story 6: Экспорт дизайн-системы и токенов
- As a UI/UX дизайнер и фронтендер
- I want экспортировать идею в Stitch DESIGN.md, Figma W3C tokens JSON и диаграмму FigJam
- So that сразу передавать артефакты в разработку.
- Acceptance criteria:
  - Генерация markdown файла DESIGN.md.
  - Генерация W3C-совместимого JSON токенов.
  - Генерация диаграммы Mermaid для FigJam.
